# Install Send to Mental Load in Chrome

1. Unzip **Send-to-Mental-Load.zip**.
2. In Chrome, open the three-dot menu and choose **Extensions → Manage extensions**.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked**.
5. Select the unzipped **send-to-mental-load** folder.
6. Open Chrome’s Extensions menu (the puzzle-piece icon) and pin **Send to Mental Load** for easy access.

On any recipe website, click the extension icon and choose **Import & queue** or **Import only**. You can also right-click the page and use the **Send to Mental Load** menu.

Keep this folder on your computer after installation. Chrome reads the extension from it.
