Privacy Policy

Last updated: 21 September 2026

Mental Load is a personal productivity application designed to help organise household and family administration, tasks, calendar events and email drafts.

Information Mental Load accesses

Mental Load may request access to Google Calendar and Gmail through Google's OAuth authentication system.

Google Calendar access is used to create, update and display calendar events requested by the user.

Gmail access is used to create and manage email drafts requested by the user.

How Google user data is used

Google user data is used only to provide the features requested by the user.

Mental Load does not use Google user data for advertising, marketing, profiling or sale to third parties.

Data storage

Authentication credentials required to connect to Google services may be securely stored by the application's backend so that authorised Google features can continue to operate.

Mental Load may also store productivity information such as tasks, notes and related application data necessary to provide its features.

Data sharing

Mental Load does not sell Google user data.

Google user data is not shared with third parties except where necessary to operate the services used by Mental Load or where required by law.

Data retention

Data is retained only for as long as necessary to provide Mental Load's functionality or until it is deleted by the user or application owner.

Revoking Google access

Google account access can be revoked at any time through the user's Google Account permissions.

Google API Services

Mental Load's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
